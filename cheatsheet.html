Cheat sheet

Umami on one page

Everything you need while working with Umami 3. Download PDF

Run it with Docker

docker compose up -d     # start
docker compose ps        # wait: healthy
docker compose logs -f umami
docker compose down      # stop, keep data
docker compose down -v   # delete data

Dashboard: http://localhost:3000
First login: admin / umami — change it at once.

Add tracking to a page

<script defer
  src="https://cloud.umami.is/script.js"
  data-website-id="YOUR-WEBSITE-ID"></script>

Put it in <head> on every page. Find it under Websites → edit (pencil) icon. Route changes in single-page apps are tracked automatically.

Track a click (HTML)

<button
  data-umami-event="Book stall"
  data-umami-event-stall="crafts">
  Book this stall
</button>

Event name: max 50 characters. data-umami-event-name adds a property. Attribute values are stored as text.

Track from JavaScript

umami.track('Reserve tickets');
umami.track('Reserve tickets', { quantity: 2 });
// links sessions, so no longer anonymous:
umami.identify('user-123');

Guard with if (window.umami) in case the tracker is blocked.

Tracker options (script attributes)

data-do-not-track="true"Respect browser Do Not Track
data-domains="a.com,b.com"Only track on these hosts
data-auto-track="false"Turn off automatic page views and events
data-exclude-search="true"Drop query strings from URLs
data-host-url="..."Send data to a different host

Server settings (environment)

DATABASE_URLPostgreSQL connection (required)
APP_SECRETRandom string securing logins
TRACKER_SCRIPT_NAMERename script.js
COLLECT_API_ENDPOINTRename /api/send
IGNORE_IPIPs to ignore, e.g. your office
SALT_ROTATIONHow often the session salt changes (default: month)

How a visitor is identified

Session ID = hash(website ID + IP
                  + user agent + monthly salt)
Visit ID   = hash(session ID + hourly salt)

No cookie. IP used in the hash, not stored. New salt each month → no link across months.

What the metrics mean

VisitorsUnique sessions (an estimate of people)
VisitsNew visit after 30 min inactive
Bounce rateVisits with 1 event ÷ visits
Visit durationFirst to last event; multi-page visits only
EventsActions, not people or purchases

Not seeing data?

  1. Website ID matches the dashboard?
  2. DevTools → Network shows /api/send?
  3. Ad blocker off for this site?
  4. Date range includes today?
  5. Hard refresh (Ctrl+F5) after editing HTML.
