Can we get useful analytics without relying on cookies?

Our short answer: yes, if we accept estimated visitor counts rather than identified individuals. Umami identifies visitors with a hash that changes every month instead of a cookie, so it can count and compare traffic without following people over time.

Umami at a glance

What it isOpen-source web and product analytics platform (MIT licence)
Built withNext.js application, Prisma, PostgreSQL database (version 3 supports PostgreSQL only)
How you add itOne <script> tag in your page's <head>
CookiesNone. Visitors are identified by a hash of website ID, IP address, user agent and a monthly salt
HostingUmami Cloud (managed) or self-hosted, for example with Docker Compose
Good forTraffic trends, referrers, devices, custom events and funnels, with minimal personal data
How this site is organised The Notes explain what Umami is and how it works. The Tutorial is a separate, step-by-step lab you do. The Cheat sheet is for quick reference while you work. Sources for everything are on the References page.
